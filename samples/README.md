# Piano samples

From the [Salamander Grand Piano V3](https://github.com/sfzinstruments/SalamanderGrandPiano) by Alexander Holm,
licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

Changes: the 16 velocity layers without the release and pedal recordings; each recording trimmed
to its first 3 to 8 seconds with a 0.4 s fade-out, converted to 44.1 kHz AAC. Made with `tools/build_samples.py`.
